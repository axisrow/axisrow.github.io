Перенос кнопки-«бутерброда» (☰) в правый верхний угол на мобильных.

## Что меняется

Только файл `styles.css`, внутри медиа-запроса `@media (max-width: 720px)` (строки ~1503–1563). HTML и JS не трогаются.

## Текущая раскладка мобильного topbar (grid 4 колонки)

```
[ AX brand ] [ ☰ ] [ пусто ] [ ◐ ]
   col 1       col 2    col 3    col 4
```

## Новая раскладка

```
[ AX brand ] [ пусто ] [ ◐ ] [ ☰ ]
   col 1         col 3    col 4    col 2→4
```

## Конкретные правки в `styles.css`

1. **`.menu-toggle`** (строка 1503–1506): `grid-column: 2` → `grid-column: 4` (крайний правый слот).
2. **`.topbar-actions`** (строка 1561–1563): `grid-column: 4` → `grid-column: 3` (займёт средний «резиновый» слот minmax(0,1fr); внутри остаётся только 44px theme-toggle, так как `.topbar-link` скрыт на мобильном — встанет вплотную слева от бутера).

`grid-template-columns: 44px 44px minmax(0, 1fr) 44px` остаётся без изменений — меняется только распределение элементов по слотам. Бренд остаётся слева, выпадающая навигация `.section-nav` разворачивается на всю ширину `left:0; right:0` от `.topbar-inner`, поэтому её позиция не изменится.

## Поведение после изменения

- На мобильном: «AX» слева → (пустота) → ◐ theme-toggle → ☰ бутерброд в крайнем правом углу.
- На десктопе (>720px): без изменений — кнопка скрыта, навигация горизонтальная.

Изменения коснутся только исходного `styles.css`. Если публикация идёт через `.pages-dist/`, после правки синхронизирую и туда (или выполню используемый билд).
